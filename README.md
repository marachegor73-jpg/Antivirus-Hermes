# HERMES

Минималистичное приложение для Windows в тёмном готическом стиле: проверка файлов, очистка временных данных и управление процессами. Интерфейс на русском языке.

## Скачать и запустить

1. Откройте [HERMES.exe в этом репозитории](https://github.com/marachegor73-jpg/Antivirus-Hermes/blob/main/downloads/HERMES.exe).
2. На странице файла нажмите **Download raw file** (значок скачивания). Либо используйте [прямое скачивание HERMES.exe](https://github.com/marachegor73-jpg/Antivirus-Hermes/raw/refs/heads/main/downloads/HERMES.exe).
3. Запустите файл на Windows 10/11 x64. Отдельно устанавливать .NET не требуется.

Готовая переносимая сборка находится в `downloads/HERMES.exe`; рядом лежит `SHA256SUMS.txt`. Её размер — около 69 МБ. Скачивайте именно `.exe`, а не исходники.

Дополнительно автоматические выпуски доступны в [Releases](https://github.com/marachegor73-jpg/Antivirus-Hermes/releases), а результаты сборок — в [Actions](https://github.com/marachegor73-jpg/Antivirus-Hermes/actions/workflows/build.yml). Для скачивания артефакта Actions нужно войти в GitHub.

Сборка не имеет коммерческой цифровой подписи, поэтому Windows может показывать предупреждение SmartScreen. Перед запуском сверяйте SHA-256 с `SHA256SUMS.txt` из той же папки или выпуска. Проверка в PowerShell:

```powershell
Get-FileHash .\HERMES.exe -Algorithm SHA256
```

## Возможности

- **Проверка угроз.** HERMES использует установленный Microsoft Defender и его актуальные определения. Можно проверить выбранный файл или папку. Результат и ошибки проверки отображаются в приложении; ошибка сканирования не означает, что файл безопасен.
- **Наблюдение за загрузками.** Пока HERMES запущен и наблюдение включено, новые файлы в папке загрузок проверяются после завершения записи. При обнаружении проблемы приложение предупреждает пользователя.
- **Карантин.** Перемещение выбранного файла выполняется только после подтверждения. Данные хранятся локально в зашифрованном виде; восстановление требует отдельного действия пользователя.
- **Очистка.** Сначала показывается список временных файлов и файлов кэша старше 24 часов с размером. Удаляются только выбранные и подтверждённые файлы. Документы, загрузки, пароли и cookies не относятся к очистке.
- **Процессы.** Показывает запущенные процессы и занятую память. Вы можете выбрать пользовательский процесс и запросить его закрытие. Принудительное завершение требует отдельного подтверждения и может привести к потере несохранённых данных. Системные и защищённые процессы заблокированы.

## Границы защиты

HERMES — интерфейс к проверке Microsoft Defender и инструментам обслуживания Windows, а не отдельный антивирусный движок. Для проверки требуется доступный Microsoft Defender. Если его компоненты выключены или недоступны, приложение сообщает об этом.

Запускаемые HERMES проверки используют `-DisableRemediation`: приложение не просит Defender автоматически устранять найденные угрозы. При этом собственная защита Windows в реальном времени работает независимо и может помещать вредоносные файлы в карантин согласно настройкам Windows. HERMES не отключает защиту Windows и не меняет её исключения.

Наблюдение за загрузками проверяет уже создаваемые или скачанные файлы. Оно не блокирует сайты, не перехватывает браузерные загрузки до скачивания и не работает после закрытия HERMES. Ни один результат проверки не гарантирует обнаружение всех угроз.

Очистка и завершение процессов не гарантируют ускорения компьютера: эффект зависит от нагрузки, объёма памяти и состояния системы. HERMES не отключает службы Windows, не изменяет реестр и не завершает процессы автоматически.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Для запуска интерфейса нужна Windows; сборку можно подготовить и на другой ОС с поддержкой Windows targeting.

```powershell
dotnet run --project Hermes.Tests/Hermes.Tests.csproj -c Release
dotnet publish Hermes.Desktop/Hermes.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableWindowsTargeting=true -o dist
```

Готовый файл: `dist/HERMES.exe`. При первом запуске .NET может извлечь внутренние библиотеки в пользовательскую временную папку.

## Автоматическая сборка и выпуск

Workflow **Build HERMES** выполняет проверки безопасности, в том числе перемещение и восстановление безвредных тестовых файлов в карантине Windows, собирает Windows-версию и запускает готовый `.exe` для проверки всех пяти страниц интерфейса. Скриншоты сохраняются в артефакт **HERMES-interface**, а `.exe` с контрольной суммой — в **HERMES-win-x64**. Его также можно запустить вручную через **Actions → Build HERMES → Run workflow**.

Публикация тега вида `v1.0.0` запускает сборку и создаёт GitHub Release с `HERMES.exe` и `SHA256SUMS.txt`:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

Для автоматического выпуска нужны разрешённые GitHub Actions и право workflow на запись в содержимое репозитория. Обычная сборка без тега выпуск не публикует.
